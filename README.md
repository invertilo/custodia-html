# CUSTODIA · Presentación

Presentación web interactiva de CUSTODIA, preparada para servirse como sitio estático desde la raíz del repositorio. `index.html` es la página de entrada que debe publicar Vercel en `https://custodia-html.vercel.app`.

## Publicar en Vercel

1. Importa el repositorio `invertilo/custodia-html` en Vercel.
2. Configura el proyecto como **Other** (sitio estático), sin build command y con `.` como output directory.
3. Despliega la rama `main`. Vercel servirá `index.html` en la raíz.

## Presentar

- Usa **← / →** o haz clic a los lados para cambiar de diapositiva.
- Pulsa **F** o el botón de pantalla completa para presentar; **Esc** sale de pantalla completa.
- Pulsa **L** para alternar idioma o usa los botones **ES / EN / עברית**.
- La última diapositiva muestra al equipo y un QR que abre [el juego CUSTODIA](https://custodia-six-phi.vercel.app).

La lluvia de estrellas y las transiciones están implementadas con CSS. El QR se obtiene de un servicio externo de códigos QR y requiere conexión al cargarlo.
